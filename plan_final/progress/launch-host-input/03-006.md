- Design decision: add a new `src/vanilla/eventQueue.ts` wrapper that defines the vanilla `event_t` shape (`evtype_t` ∈ {keydown, keyup, mouse, quit}, fields data1/data2/data3), the canonical MAXEVENTS=64 circular queue (matching d_event.h), and pure functions translating Win32 keyboard/mouse/close/focus messages into vanilla events. The keyboard translator handles both WM_KEYDOWN/UP and WM_SYSKEYDOWN/UP (the latter is how Alt-F4 arrives — VK_F4 with bit 29 of LPARAM set indicating Alt is held). The mouse translator transforms WM_*BUTTONDOWN/UP into an updated button bitmask plus an ev_mouse event with data1=button mask, data2=0 (delta-x), data3=0 (delta-y). The close translator handles WM_CLOSE → ev_quit. Focus handling reports a focus state change, not an event. The queue itself is a circular buffer with `post(event)` / `pull()` / `drainAll()` matching D_PostEvent / D_ProcessEvents. No `src/host/` or `src/input/` file is modified.
